AI Agent with Tool Calling
An AI Agent built using Ollama, Qwen 2.5, and Python that follows a Plan → Action → Observe → Output reasoning framework.

The agent analyzes user queries, selects appropriate tools, executes them, observes the results, and generates final responses.

Features
Weather Information Tool
Stock Price Tool using Yahoo Finance (yfinance)
System Command Execution Tool
JSON-based Agent Workflow
Local LLM Inference with Ollama
Modular Tool Architecture
Tech Stack
Python
Ollama
Qwen 2.5 Coder
yfinance
Requests
OpenAI Python SDK
Workflow
User Query → Plan → Tool Selection → Action → Observation → Final Response

Example Queries
What is the weather in Hyderabad?
What is the stock price of AAPL?
What files are in the current directory?
This project demonstrates the fundamentals of AI agents, tool calling, reasoning loops, and local LLM integration.
